Get started with QuickTrim

QuickTrim splits a file into regions. You bin the regions you don’t want, then export the rest as a new file. Your original is never changed.

Open a file

  • Drag a video or audio file onto the QuickTrim window.
  • Or choose File > Open (⌘O).
  • Or Control-click a file in the Finder and choose Open With > QuickTrim.

If the current window is empty, the file opens in it. Otherwise it opens in a new window, so you can work on several files at once. Choose File > New Window (⌘N) for another empty window.

Make your first trim

  1. Play with Space, or click anywhere on the timeline to move the playhead.
  2. At the start of a section you want to remove, press M to mark a cut. Do the same at its end.
  3. Move the playhead into that section and press B to bin it. It turns red.
  4. Click Export, choose a name and location, and click Save.
Turn on Preview before exporting to watch or hear exactly what the exported file will contain.

Supported files

QuickTrim opens files that macOS can play: video such as MOV, MP4 and M4V, and audio such as MP3, M4A, AIFF and WAV. Some formats, such as many AVI files, can’t be played by macOS and won’t open.
